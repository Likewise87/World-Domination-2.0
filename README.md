# World Domination 2.0

RimWorld mod by **TSA**. If [Rim War](https://steamcommunity.com/sharedfiles/filedetails/?id=2222935097) and [Vanilla Outposts Expanded](https://steamcommunity.com/sharedfiles/filedetails/?id=2688941031) had a child, this would be it.

**[Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3680501610)** · **[Player guide](https://likewise87.github.io/World-Domination-2.0/)**

> The player guide is a **work in progress**. It is not linked from Steam yet. Prefer in-game tooltips if something in the guide disagrees with the live mod.

## What this mod does

- NPC factions act on the world map through **travelers** (raid, trade, expand, roads, and more)
- Build and upgrade your own **outposts** for production, logistics, artillery, and defense
- Fight and resolve **world-map battles**, including attacks on your colony and outposts
- Use **diplomacy**, allies, and late-game escalation as the map heats up
- Tune almost everything in **Mod Settings**

## Requirements

- RimWorld 1.6
- [Harmony](https://steamcommunity.com/workshop/filedetails/?id=2009463077)
- [Vanilla Expanded Framework](https://steamcommunity.com/sharedfiles/filedetails/?id=2023507013)
