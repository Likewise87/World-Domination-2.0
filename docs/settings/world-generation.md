# World generation settings

This advanced page controls the relative tier weights assigned to World Domination settlements during initial generation.

| Starting tier | Default weight | Default share |
|---|---:|---:|
| Tier 1 outpost | 150 | 75% |
| Tier 2 town | 45 | 22.5% |
| Tier 3 fortress | 4 | 2% |
| Tier 4 citadel | 1 | 0.5% |

Weights are relative. Changing one value changes the displayed percentage shares of all four tiers.

## Reroll settlement tiers now

This button appears only while playing. After confirmation, it rerolls existing settlement tiers using the current weights. It is a destructive action button, not a setting and has no default value. Reset restores the four weights above but does not reroll settlements automatically.
